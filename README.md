# HateHero Studio VIP PWA

Projek ini sudah siap dengan:
- Kod asal `test.tsx` sebagai `src/App.tsx`
- Web App Manifest
- Service Worker
- Ikon maskable 192x192 dan 512x512
- Pendaftaran Service Worker
- Mod standalone dan portrait

## Guna

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```

Deploy folder `dist` ke hosting HTTPS. Selepas dibuka di Chrome Android, pilih **Install app**.
